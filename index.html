五个最硬的事实

A市场在投票选 3D,不是视频

58 同城/安居客研究院《2026年百万房产经纪人生存报告》 · 2026-07-02 · 新华社《经济参考报》报道,人民网、南方+ 交叉印证
VR 看房 26.6% → 45.0%(升至第一);视频看房 37.9% → 20.9%。同时经纪人 AI 使用率 49.7%(一线 58.9%),但用途全部停在文案层,无一项指向"生成可播放的讲解内容"。

A端到端视频模型在运镜上主动认输

OpenAI 官方文档,经 Microsoft Learn · 2026-09-29 核验
Sora 2 官方自述难以处理 precise time-based event sequencing such as camera movement,且输入上限两张图;同文档列出 spatial reasoning(分清左右)亦有困难。而房产讲解恰恰要求空间准确 + 覆盖完整 + 运镜可控。

A看起来免费的开源,商用都有坑

各仓库 LICENSE 原文,GitHub API 实测 · 2026-09-29
LivePortrait 的 InsightFace 仅限非商业研究;HeyGem/DUIX MAU>1000 强制商业授权+ 强制署名;Wav2Lip 无 LICENSE 文件;LTX-2.x 年营收 ≥$10M 须付费许可;HunyuanVideo 排除欧盟/英国/韩国;3DGS 系仓库字段均为 NOASSERTION。8 个开源视频模型中仅 4 个无条件可商用。

A合规是前置条件,不是加分项

cac.gov.cn 原文逐条读取
《深度合成管理规定》第十四条:人脸/人声编辑须取得被编辑者"单独同意"(肖像授权,非内容标识)。《标识办法》2025-09-01 施行:数字人视频同时命中"视频"与"虚拟场景"两类,标识要求叠加;元数据须含服务提供者名称/编码。

A算力根本不是瓶颈

RunPod / Lambda / AWS 官方定价页 · 查询日 2026-09-29
RTX 4090 $0.34/h,重建一套户型约 $34,6 个月总 GPU 费百美元级——远低于一名实习 6 个月的人力成本。瓶颈在"人对房产领域的建模",而评测集恰好是 GPU 造不出、人能造的东西。

两个必须先知道的竞品事实

⚠️ 写 PPT 前必读 —  下面两条如果不主动说,大概率会被对方问出来。

ACinemaTraj 几乎逐字命中需求 2

arxiv.org/abs/2607.26910 · 2026-07-29 · CC BY 4.0
LLM agent + 结构化 3D 场景图,把讲解意图分解为原子电影运镜(dolly/orbit/crane/pan/tilt/zoom/arc),参数化轨迹可针对碰撞避免优化,并生成与相机运动对齐的同步旁白与字幕。摘要原句:applications ranging from real-estate advertising to virtual tour creation。

含义:既不能把"提出这个思路"当卖点(已是 2 个月前的公开研究),但正好提供了顶会级可复现基线 —— 你的价值在落地管线与垂直评测集。

B贝壳如视 2019 年就有 AI 讲房

贝壳技术副总裁惠新宸对外披露 · 环球网转述公司新闻稿 · 未找到贝壳原始发布,故为 B 级
C 端上线 AI 讲房,基于 TTS 从周边配套/小区/户型结构/交易信息四维度自动生成讲稿,"3 秒生成讲房"。用户单次收听完成率 73.8%,VR 房源超 118 万套。

含义:需求 1 不是新东西。差异化在于预生成文案播报 vs 数字人在 3D 场景里指着具体位置说话 —— 讲解与空间绑定。

ASora 2 官方自述的技术缺陷

Microsoft Learn 官方文档 · 2026-09-29 核验
PPT:强证据
原文自述难以处理 precise time-based event sequencing such as camera movement、spatial reasoning;输入上限两张图。Seedance 2.0 支持 9 图+3 视频+3 音频参考。厂商自证的缺陷,比第三方评测更有力。

ACamCtrl3D:"轨迹→视频"已被顶会验证

arxiv.org/abs/2501.06006 · 3DV 2025 · Microsoft Research
PPT:可用
给定相机轨迹生成 fly-through 视频可行。但其输入是单图+轨迹,非 3D 模型;我们已有 3D 资产,用引擎离线渲染即可,不需要生成模型。定位为备选路线/对照组。

A语音对齐是现成 API 能力

Azure TTS 官方 SSML 文档 + WhisperX (BSD-2-Clause, ★24,294)
PPT:可用
Azure 支持 bookmark(词级 offset/duration)与 viseme(音素→视素)事件标签;WhisperX 提供词级时间戳。运镜对齐不需要自研对齐器。
⚠️ 但 bookmark/viseme 字段结构未逐字核实,该推断依赖这一点。

ACinemaTraj:最接近本项目的公开研究

arxiv.org/abs/2607.26910 · 2026-07-29 · 项目页
PPT:建议主位
四段式架构:3D 场景图 → 原子运镜分解 → 碰撞避免优化 → 旁白对齐。可直接作为系统设计蓝本,也是可复现可对比的基线。但不能把"提出这个思路"当原创贡献。

A交付边界:不能承诺什么

依据仓库生态规模与头部团队 JD 结构

A合规:肖像"单独同意"是最高优先级

cac.gov.cn/2022-12/11/c_1672221949354811.htm · 2023-01-10 施行
PPT:必引
《深度合成管理规定》第十四条:人脸/人声编辑须提示使用者告知被编辑个人并取得"单独同意"。
第一份要签的文件不是算法协议,而是主播本人的肖像与声音授权书,且不能被概括性隐私政策吞掉。

A合规:内容标识双类叠加

cac.gov.cn/2025-03/14/c_1743654684782215.htm · 2025-09-01 施行
PPT:必引
《标识办法》第四条:视频"起始画面和播放周边"显著标识 + 虚拟场景"起始画面"显著标识 → 数字人视频双类叠加执行。第五条:元数据须含服务提供者名称/编码。第九条:唯一免标识出口,代价是日志留存 ≥6 个月。
