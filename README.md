### 三条硬规矩

1. **C 级内容不能进结论页。** 库中标 `⚠️ 未核验` 的条目只能当线索,不得作为方案依据或收益承诺。

2. **许可证必须带日期。** 本领域开源方案的商用限制变化极快:
   - LivePortrait / DUIX / 3DGS 系仓库均有商用限制
   - 所有 3D 相关核心仓库的 GitHub 许可证字段为 `NOASSERTION`

## 三个最重要的发现

### 1. 市场在投票选 3D,不是视频 `[事实]`
58 同城/安居客研究院《2026年百万房产经纪人生存报告》(2026-07-02,新华社经参网报道):

| 房源呈现方式 | 2025 | 2026 |
|---|---|---|
| VR 看房 | 26.6% | **45.0%(升至第一)** |
| 视频看房 | 37.9% | **20.9%** |
| 文字展示 | — | 4.6% |

同时经纪人 AI 使用率 49.7%(一线 58.9%),但用途**全部停留在文案层**,无一项指向"生成可播放的讲解内容"。

### 2. 许可证比算法更可能卡住项目 `[事实]`

**数字人侧**:MuseTalk(MIT+模型可商用)✅、LatentSync(Apache-2.0)✅、LiveTalking(Apache-2.0)✅;LivePortrait 的 InsightFace **仅限非商业研究**⚠️、HeyGem/DUIX **MAU>1000 强制商业授权**❌、Wav2Lip **无 LICENSE 文件**❌

**视频侧**:8 个开源视频模型**仅 4 个无条件可商用**。HunyuanVideo **排除欧盟/英国/韩国**、LTX-2.x **年营收 ≥$10M 须付费许可**、初版 HunyuanVideo **无 LICENSE 文件**

**3D 侧**:3DGS / instant-ngp / COLMAP / Open3D 字段**全部 `NOASSERTION`**

> ⚠️ GitHub 的 license 标签**不可信**——腾讯与 LTX 都返回 `NOASSERTION`,必须读 LICENSE 原文。

### 3. 算力不是瓶颈,人建模才是 `[推断]`
RTX 4090 租 **$0.34/h**,重建一套户型约 $34,6 个月总 GPU 费百美元级——**远低于一名实习 6 个月的人力成本**。
瓶颈在"人对房产领域的建模",而评测集恰好是 GPU 造不出、人能造的东西。

## ⚠️ 两个必须先知道的竞品事实

### CinemaTraj 几乎逐字命中需求 2 `[事实]`
**arXiv:2607.26910**(2026-07-29):LLM agent + 结构化 3D 场景图 → 讲解意图分解为原子运镜 → 碰撞避免优化 → **与相机运动对齐的同步旁白**。摘要原句:`applications ranging from real-estate advertising to virtual tour creation`。

`[推断]` **不能把"提出这个思路"当卖点**(已是 2 个月前的公开研究),但它提供了顶会级可复现基线 —— 你的价值在落地管线与垂直评测集。

### 贝壳如视 2019 年就有 AI 讲房 `[事实/B级]`
C 端上线,基于 TTS 四维度自动生成讲稿,"3 秒生成讲房"。**用户单次收听完成率 73.8%**,VR 房源超 118 万套。
来源:贝壳技术副总裁惠新宸对外披露,环球网转述(**未找到贝壳原始发布**)

`[推断]` **需求 1 不是新东西。** 差异化在于:预生成文案播报 vs **数字人在 3D 场景里指着具体位置说话**。

### Sora 2 官方自证运镜缺陷 `[事实]`
> `precise time-based event sequencing such as camera movement` + 输入上限两张图

`[推断]` 这是"为什么不用端到端 AI 视频"最有力的论据,**而且是厂商自己说的**。而我们已有 3D 模型,直接引擎离线渲染即可,根本不需要生成模型。
